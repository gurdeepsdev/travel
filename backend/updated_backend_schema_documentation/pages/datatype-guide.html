Text rules that should apply consistently

  • Count limits in characters after Unicode normalization, not raw bytes.
  • Trim accidental leading/trailing whitespace, but preserve intentional internal whitespace.
  • Use case-insensitive uniqueness for usernames/emails where product rules require it.
  • Never truncate silently; reject with a field-level validation message.
  • Do not store raw tokens, OTPs, or passwords—store keyed or salted hashes as appropriate.
  • Define enumerated values with database CHECK constraints and matching API enums.
