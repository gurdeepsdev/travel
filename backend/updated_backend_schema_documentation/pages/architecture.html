Architecture map

Schemas are treated as ownership boundaries. Cross-schema foreign keys are contracts: changes to identifiers, deletion, or lifecycle rules require coordination between both domains.

identities — Maps an account to login identifiers such as email, phone number, or device identity.
sessions — Tracks refreshable login sessions and the device/network context in which they were issued.
otp_requests — Controls OTP challenges, retry limits, verification state, and expiry.
login_history — Provides a security audit trail for successful and failed login attempts.

saved_items — Records items bookmarked by a user for later access.

collection — Groups saved content into a user-managed collection.
blocked_users — Enforces one-way user blocking relationships.

users_reports — Records moderation reports submitted by one user about another user or content.

Principal anchors

  • auth.users is the account identity root referenced throughout the product.
  • media.assets centralizes media, while usage tables attach assets to feature records.
  • itinerary.itineraries is reused by chat, sharing, and explore content.
  • trip.trips, group.groups, and community.communities are collaboration/planning aggregates with membership or child records.
